# Promptly

**Select anything. Ask any AI.**

[English](README.md) · [中文](README.zh-CN.md)

See website: https://onesun2012.github.io/promptly/

Download: https://github.com/onesun2012/promptly/releases/latest

Local-first BYOK selection AI for Windows. No account, no relay, zero content telemetry.

![toolbar](site/img/toolbar.jpg)

## Features
- Three-state selection toolbar
- Floating ball
- BYOK OpenAI-compatible / Anthropic / Gemini
- Screenshot vision in chat
- Local SQLite + DPAPI keys
- 10 languages

## Quick start
1. Install Setup from Releases
2. Settings → Provider lab → Test → Save
3. Select text → Translate
